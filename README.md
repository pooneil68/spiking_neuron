# spiking_neuron

Matlab codes for a blog entry at https://pooneil.sakura.ne.jp/archives/permalink/001823.php
The aim of these codes is to replicate Figure 4.10 in the fourth chapter of Izhikevich, E.M. (2007) [Dynamical Systems in Neuroscience](https://doi.org/10.7551/mitpress/2526.001.0001). MIT Press, Cambridge.
